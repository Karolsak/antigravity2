Problem Statement

The stator of a 600 hp, 1160 r/min, 575 V, 3-phase, 60 Hz induction motor has 90 slots, an internal diameter of 20 inches, and an axial length of 16 inches. Calculate: (a) number of coils; (b) coils per phase; (c) coils per group; (d) coil pitch in mm; (e) area of one pole; (f) flux per pole if B_avg = 0.54 T.

Step 0 — Determine Number of Poles

Ns = 120·f/p → for f=60 Hz, p=6: Ns = 120×60/6 = 1200 rpm
Slip s = (Ns−Nr)/Ns = (1200−1160)/1200 = 3.33% ✓ (reasonable)
✅ p = 6 poles, Ns = 1200 rpm, s_fl = 3.33%

(a) Number of Coils on Stator

For a standard double-layer winding, each slot contains 2 coil sides. Total coil sides = 2 × S. Each coil has 2 sides → coils = slots.

Number of coils = S = 90
✅ 90 coils

(b) Coils per Phase

Coils/phase = S / m = 90 / 3 = 30
✅ 30 coils/phase

(c) Coils per Group

Each phase has one group per pole → groups per phase = p = 6. Alternatively: q = S/(p·m).

Coils/group = S / (p × m) = 90 / (6 × 3) = 90 / 18 = 5
✅ 5 coils/group | Slot pitch angle α = 180°×p/S = 12°

(d) Coil Pitch (Full Pitch = Pole Pitch)

D = 20 in × 25.4 mm/in = 508 mm
τ_p = π·D / p = π × 508 / 6 = 266.1 mm
Slot pitch τ_s = π·D / S = π × 508 / 90 = 17.74 mm
Full-pitch coil spans = S/p = 90/6 = 15 slots
✅ Coil pitch = 266.1 mm

(e) Area of One Pole

L = 16 in × 25.4 mm/in = 406.4 mm = 0.4064 m
A_pole = τ_p × L = (π·D/p) × L
A_pole = 0.26598 m × 0.4064 m = 0.10808 m²
✅ A_pole = 0.1081 m² = 108,144 mm²

(f) Flux per Pole (B_avg = 0.54 T)

Φ = B_avg × A_pole = 0.54 × 0.10808
Φ = 0.05836 Wb = 58.36 mWb
✅ Φ = 58.36 mWb

Winding Factor

α (slot angle) = 180°×p/S = 180×6/90 = 12° (electrical)
kd = sin(q·α/2) / (q·sin(α/2)) = sin(5×6°)/(5×sin(6°)) = sin30°/(5×0.10453) = 0.9567
kp = sin(90° × pitch/pole_pitch) = sin(90°) = 1.000 (full pitch)
kw = kd × kp = 0.9567 × 1.000 = 0.9567
✅ Winding factor k_w = 0.9567
